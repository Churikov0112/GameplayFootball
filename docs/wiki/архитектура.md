# Архитектура

## Кратко

3D-футбольная игра на C++17/CMake 3.16+: форк заброшенного GameplayFootball, обновлённый под
SDL3 (SDL3_image/SDL3_ttf)/OpenGL/OpenAL/Boost/SQLite3 и собранный по изменениям Google Brain.
Работает offline, локально: один процесс `gameplayfootball`, окно + ввод с клавиатуры/геймпада.
Движок «Blunted2» живёт в `src/` рядом с игрой (не отдельная библиотека).

## Сквозной путь

```
main() → Properties(football.config)
  → Database.Load("databases/default/database.sqlite")
  → SystemManager: RegisterSystem(GraphicsSystem, AudioSystem)
  → Scene2D + Scene3D → ObjectFactory
  → Scheduler: TaskSequence "game" (10 мс) + TaskSequence "graphics" (непрерывно)
  → Run()
```

Поток данных за тик:

1. **game** (тик `physics_frametime_ms` = 10 мс): `MenuTask::Get` → `GameTask::Get`
   (обрабатывает messageQueue, `match->Get()` читает ввод) → `GameTask::Process`
   (`match->Process()` считает симуляцию, потом `PreparePutBuffers`).
2. **graphics** (непрерывный): `GameTask::Put` (рисует в Put-буферы из Get-буферов) →
   `GraphicsSystem::Get/Process/Put` (рендер в отдельном потоке `OpenGLRenderer3D`).

Сцену переключают сообщения `GameTask::Action(e_GameTaskMessage_*)` — старт/стоп матча и меню-сцены.
Игровые объекты создаются через `ObjectFactory` и регистрируются в сценах (`scene3D->CreateSystemObjects`).

## Рендер (OpenGL 3.2 core)

- Рендерер `OpenGLRenderer3D` (`src/systems/graphics/rendering/`) создаёт **core
  profile 3.2** контекст (`SDL_GL_CONTEXT_MAJOR_VERSION=3`, `MINOR=2`,
  `SDL_GL_CONTEXT_PROFILE_CORE`) — без fixed-function (нет `glBegin`/матричного
  стека/`glLight*`/client-side arrays). Контракт в `sdl_glfuncs.h`: deprecated-
  функции помечены `SDL_PROC_UNUSED` и не запрашиваются у драйвера (под core
  profile `SDL_GL_GetProcAddress` вернул бы NULL и лоадер упал бы).
- Весь рендер — через шейдеры (`#version 150`) и VAO/VBO: геометрия
  (`simple`/`zphase`), deferred-освещение (`ambient`+`lighting`, fullscreen-квад),
  пост-процесс (`postprocess`), 2D-оверлей (`overlay`). Light-типы: в игре всегда
  directional (`light.type == 0`), ветка point-light-сферы была dead code и убрана.
- Интерфейс `Renderer3D` очищен от мёртвых legacy-методов (`SetColor`,
  `SetTextureMode`, `RenderAABB`, `SetLight`, `SetClientTextureUnit`,
  `PushAttribute`/`PopAttribute`, `SetColorMask`, HDR-захват яркости) — они не
  вызывались игровым кодом и держали fixed-function GL.
- Шейдеры ещё `#version 150` (desktop GL), не `#version 300 es` — перевод на
  GLES (две ветки шейдеров) отложен, см. [[открытые-вопросы]].

## Инварианты проекта

- **Один `time_ms`** — глобальный extern (`src/gamedefines.hpp:16`). Источник истины —
  `EnvironmentManager::GetTime_ms()`; параллельное время не заводить. Исключение: симуляция
  матча (`Match::Process`) отвязана от реальных часов — время продвигается фиксированным шагом
  10 мс за вызов (`actualTime_ms += 10`), что делает headless-прогоны детерминированными.
- **Get/Process/Put и мьютексы.** Игровая логика и рендер в разных потоках; границы защищают
  `matchPutBufferMutex`, `matchLifetimeMutex`, `getPhaseMutex`. Ломать блокировки — сегфолт на выходе.
- **Boost-идиомы**: `boost::intrusive_ptr`/`boost::shared_ptr`, `boost::signals2`, `boost::thread`.
- **Физика (ODE) не компилируется** для игры; правки в `src/systems/physics/*` не соберутся.

## Headless-инструменты

- **Игровой контекст вынесен** в `src/gamecontext.*` (глобальные переменные и геттеры,
  которые раньше жили в `main.cpp`): `scene2D`, `scene3D`, `graphicsSystem`, `audioSystem`,
  `db`, `config`, `menuTask`, `gameTask`, pilons, `controllers`. Инициализация — `InitGameContext()`,
  очистка — `ShutdownGameContext()`. Это позволяет отдельным бинарникам линковать контекст
  без `main.cpp` (в котором `main()`).
- **`tools/determinism`** — headless-раннер детерминизма: `run` (печатает SHA-1 состояния
  матча после 5000 тиков с сидом 42) и `check <hash>` (сравнивает с эталоном, код выхода 0/1).
  В начале ФИКСИРУЕТ ключи конфига (`graphics3d_renderer=mock`, `audio_renderer=mock`,
  `match_difficulty=0.8`, `match_duration=1.0`), так что хэш не зависит от `football.config`.
  Эталоны — на платформу: `reference.txt` (Windows x86), `reference-windows-x64.txt`,
  `reference-linux.txt` (последние два — см. [[открытые-вопросы]]). Использует
  `EnvState`-сериализацию (`src/defines.hpp`) и `Match::ProcessState` (см. [[матч]]).
- **`MockRenderer3D`** (`src/systems/graphics/rendering/mock_renderer3d.hpp`) — заглушка рендерера
  без окна/GL-контекста; включается ключом конфига `graphics3d_renderer=mock`. Игра по умолчанию
  использует OpenGL, mock — только для headless-тулов.

## Сборка

- **Сборка**: CMake 3.16+, C++17; единый статический `blunted2` (из бывших OBJECT-библиотек) +
  игровые библиотеки; SDL3-таргеты `SDL3::SDL3`, `SDL3_image::SDL3_image`, `SDL3_ttf::SDL3_ttf`.
  SDL_gfx не используется вовсе (в vcpkg его нет; заменён на `SDL_ScaleSurface`). Физика (ODE)
  по-прежнему не собирается. Windows-игра — GUI (`WIN32`) со своей WinMain-заглушкой в
  `src/main.cpp` (SDL3 не даёт SDLmain). Дистрибутивный Boost (Ubuntu/Homebrew) не даёт
  компонентных CMake-конфигов, поэтому `Boost_NO_BOOST_CMAKE=ON` + компоненты
  `thread filesystem` (`Boost.System` — header-only с 1.69, не линкуется). Linux: игровые
  статические библиотеки имеют циклические ссылки (`hidlib` ↔ `gamecontextlib`) — на GNU ld
  они линкуются через `-Wl,--start-group/-end-group` (`CMakeLists.txt`, только `UNIX AND NOT APPLE`;
  MSVC/ld64 терпят плоский порядок).
- **Headless-звук**: `determinism_runner` ставит `audio_renderer=mock` — `MockAudioRenderer`
  (`src/systems/audio/rendering/mock_audiorenderer.hpp`) реализует `AudioRenderer` no-op'ами,
  т.к. на headless-машинах может не быть аудио-устройства, и `OpenALRenderer::CreateContext`
  падает фатально.

## Что пробовали и отвергли

- **Google Brain (ветка `google_brain`)** — RL-обвязка для исследования; выброшены меню, звук, HUD.
  Цель форка — вернуть их и собрать игру на многих платформах. Не вливать ветку целиком.
- **Windows-линия (ветка `windows`)** — отдельная ветка сборки; нужные MSVC-правки
  (NOMINMAX, `std::vector` вместо VLA, сигнатура `main(int, char**)`) перенесены в `master`,
  ветку целиком не вливать. Сборка подтверждена end-to-end на MSVC (VS2022 Build Tools,
  vcpkg `x86-windows`, см. `AGENTS.md`).
- **Вендорный SQLite** — убран в `68159a2`, сборка использует системный пакет.
